# 데이터 분석 문제 정의

## 데이터를 고른 이유
- ClinVar Conflicting Classifications는 실제 임상 유전체 데이터로, 유전 변이의 특성(대립유전자 빈도, 변이 위치, 유전자, 기능적 영향 등)과 병원성 사이의 관계를 다루는 실전형 데이터셋이다.
- 특성 종류가 다양하다 — 수치형(대립유전자 빈도, 아미노산 치환 점수 등), 범주형(유전자, 변이 결과 유형, 염색체 등), 구조화된 텍스트(위치 정보)가 섞여 있어 전처리·특성 엔지니어링 연습에 적합하다.
- 연속형 타겟(`CADD_PHRED`, 변이 병원성 점수)과 이진 타겟(`CLASS`, 임상 해석 상충 여부)을 모두 포함하고 있어 회귀와 분류 문제로 모두 확장할 수 있다.
- 65,188행 규모로 선형회귀부터 랜덤포레스트, XGBoost까지 여러 모델을 비교하기에 적당한 크기이며, 결측치·불균형 등 실제 데이터 분석에서 마주치는 이슈를 그대로 담고 있다.

## 오늘 풀 문제
1. 대립유전자 빈도, 변이 위치, 유전자 등 다른 특성들로 `CADD_PHRED`(변이 병원성 점수)를 예측할 수 있는가?
2. 선형회귀 대비 랜덤포레스트·XGBoost(그래디언트부스팅) 같은 비선형 트리 기반 모델이 예측 성능을 얼마나 개선하는가?
3. RMSE, MAE, R² 세 지표로 모델 성능을 비교했을 때 어떤 모델이 가장 우수하며, 어떤 특성이 예측에 가장 중요한가?

## 오늘 데이터에서 확인해볼 것
1. 데이터 구조와 결측치 현황 — 전체 컬럼별 결측 비율, 특히 회귀 타겟인 `CADD_PHRED`의 결측 여부와 비율
2. 타겟 변수(`CADD_PHRED`)의 분포와 주요 특성(대립유전자 빈도, `BLOSUM62`, `IMPACT` 등)과의 상관관계
3. 범주형 변수의 카디널리티(유전자 수, `Consequence` 종류 수 등)를 확인하고 인코딩 방식(원-핫, 빈도 인코딩 등)을 결정

## 회귀분석 기준선 (Baseline)
모델 성능을 비교할 때 "이 정도면 잘한 것인지"를 판단하려면 기준점이 필요하다. 두 단계로 기준선을 정의한다.

**1) 순수 기준선 (Naive Baseline)** — 아무 특성도 쓰지 않고 훈련 데이터의 평균값(`CADD_PHRED` 평균 ≈ 15.68)만 예측하는 모델. 모든 실제 모델은 최소한 이 값보다는 나아야 의미가 있다.

| 지표 | 값 |
|---|---|
| RMSE | 10.770 |
| MAE | 9.107 |
| R² | 0.000 (정의상 0) |

**2) 모델 기준선 (Baseline Model)** — 실제 특성을 사용하는 모델 중 가장 단순한 **선형회귀(LinearRegression)** 를 기준 모델로 삼는다. 랜덤포레스트·XGBoost는 이 선형회귀 대비 얼마나 개선되는지로 평가한다.

| 지표 | 값 |
|---|---|
| RMSE | 6.366 |
| MAE | 5.044 |
| R² | 0.651 |

→ 선형회귀만으로도 순수 기준선 대비 RMSE가 약 41% 감소(10.77→6.37), R²가 0→0.65로 개선되어 특성들이 `CADD_PHRED` 예측에 실질적인 설명력을 가진다는 것을 확인할 수 있다. 이후 랜덤포레스트·XGBoost 및 피처 엔지니어링·튜닝의 효과는 이 선형회귀 기준선 대비 개선폭으로 평가한다.
